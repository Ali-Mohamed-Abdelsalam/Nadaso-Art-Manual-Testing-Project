# Nadasso Art – Manual Testing Project

## Project Overview

This project documents the manual testing of the Nadasso Art online store. The goal was to verify the website's main features, navigation, forms, product pages, and ordering flows.

**Website:** https://nadassoart.com/wd

## Testing Scope

The testing covered the following areas:

* **Login & Authentication:** Valid and invalid login credentials and required-field validation.
* **Registration & Password Reset:** Account creation and password reset scenarios.
* **Navigation:** Header and footer links, page navigation, and cart access.
* **Product Pages:** Product images, names, prices, sizes, and available actions.
* **Collection & Sorting:** Product listing and sorting by price and size.
* **Cart & Ordering:** Adding products to the cart, cart total calculations, and order form validation.
* **Contact & Language:** WhatsApp links, contact actions, and English/Arabic language switching.

## Testing Approach

Manual testing was performed using documented test cases, step-by-step execution, and verification of actual results against expected results. Both positive and negative scenarios were included.
